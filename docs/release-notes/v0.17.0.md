# Release v0.17.0

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.0/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.0/docs/release-notes/README.md)

A query line you can type into, clicks that finish within a 120 Hz frame, and a
fifth of the memory.

## Desktop

- The command rail becomes one query line over the results. Class, objective,
  loadout, upgrades, handling, scaling, results, and limits are parts of the
  sentence; click one to edit it in place, and type stats into the ribbon below.
- **Ctrl+K** edits anything by typing, such as `str 40`, `lock dex 30`, a weapon,
  a skill, `+20`, or `top 10`. Matches are highlighted and recent commands come
  first.
- **Ctrl+Z** and **Ctrl+Y** undo and redo any query change. Automatic weapon
  follow-ups belong to the edit that caused them, and a profile change starts a
  fresh history.
- After **Update Results**, each rank shows how far its loadout moved and how its
  score changed, and Build Detail states the selected rank and its gap to #1.
- AR, skill damage, the objective, and rank sort from their column headers
  without renumbering ranks. Keyboard and screen readers follow the sorted order.
- **Ctrl+Enter** searches, **Ctrl+1** to **Ctrl+4** switch workspaces, arrow keys
  move between ranked rows, and **?** lists every shortcut.
- Compare shows its active filters as removable chips with one **Filters** panel,
  and Build Detail reads as rows with its key numbers set large.
- Motion explains changes: a re-ranked list settles into place, the workspace tab
  highlight slides, editors open from their trigger, and values changed by undo or
  the palette flash where they live. Searches show a progress bar that fills with
  each update, and the first search fills the board with placeholder rows. All of
  it respects the system reduced-motion setting.
- The empty Rankings grid, the selected row's unavailable text, and the Compare
  upgrade matrix now meet WCAG A/AA.

## Speed and footprint

- Every click finishes within about one 120 Hz frame on the GPU-composited
  desktop: a column sort takes 7.7 ms instead of 18.5 ms, returning to Rankings
  5.5 ms instead of 18.3 ms, and opening Compare 8.5 ms instead of 20.9 ms. New
  results land in 17 ms instead of 29 ms.
- Search preparation runs in parallel per thread, so an open search takes about
  80 ms instead of 430 ms, with identical results. Bleed searches no longer have
  occasional 25 to 44 second outliers, and progress and completion appear sooner.
- The app uses about 180 MB when idle instead of about 1.1 GB, and about 350 MB
  instead of 1.3 GB after heavy use. One data table reserved 482 MB per profile for
  about 190 entries.
- The portable executable is 12.5 MB instead of 17.6 MB, and the app reaches its
  loaded data about 150 ms sooner.

See the [performance measurements](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.0/docs/performance.md#responsiveness-work-2026-10-01)
for methods and limits.

## Data compatibility and limits

The bundled data and the scoring model are unchanged: snapshot schema **6** and
runtime model **`aow-routes-effects-v9/exact-v3`**, so builds saved with v0.16.0
load with their results. The game profiles remain Vanilla **1.17** and Convergence
**3.0.0.1**. Convergence retains its documented experimental feature limits.

AR and status values do not include enemy defenses, resistance growth, or status
proc damage. Sequence totals assume the modeled contacts connect. War Cry and
Barbaric Roar's attack-power self-buffs are not modeled. This release does not
claim live in-game verification of every skill.

## Verification

The release source passed 241 core tests, 61 backend tests, 201 frontend unit
tests, 166 browser tests, 17 Node contract checks, and 7 native-responsiveness
metric tests; release-mode benchmarks, which are opt-in, were not run. Frontend
lint and the production build, Clippy and formatting for both Rust crates, the
snapshot validator, 122 Python extraction and validation-tool tests, release
metadata validation, and documentation link checks also passed. Five packaging
tests that need PowerShell 7 were skipped locally and run in CI.

The release executable passed the packaged WebView2 smoke test with the version
bump, using its compressed embedded data. A seeded external reference comparison
against the pinned T. Clark 1.17 calculator passed all 632 Vanilla weapon AR and
base status cases, covering 100 weapons and the 32 Bloodfiend's Fork boundary
cases at zero, random, and maximum upgrades in both handling modes. The largest AR
component difference was 0.00008, within the 0.001 tolerance, and all 348
applicable selected-skill identities matched. The exhaustive raw-data check also
passed for both profiles: every candidate weapon and Ash pair (382,220 Vanilla,
389,058 Convergence) matched the raw regulation mount permissions, and all 364,304
Vanilla and 601,140 Convergence legal configurations evaluated without errors apart
from documented unsupported cases, including 255,208 materialized Vanilla skill
routes. Neither check verifies skill damage formulas.

Identical searches returned identical ranked results before and after the memory
and size changes. Timings were measured on one Windows desktop with a 240 Hz
display; the performance measurements record their methods and variation.
Versioned packages must pass the release workflow's package checks before
publication. Installation, upgrade, and uninstall on a clean Windows machine were
not exercised. The release build report records the final source commit, package
checks, and signing status.
