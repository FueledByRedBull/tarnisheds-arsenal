# Release v0.14.1

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.14.1/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.14.1/docs/release-notes/README.md)

A focused hotfix for chart accuracy, tradeoff explanations, and data validation.

## Changes

- Affinity Watch uses the same padded scale for axis labels, grid lines, and
  plotted values, including constant-value series.
- AR sacrifice is explicitly relative to the maximum AR of the **selected fixed
  loadout**, not the highest AR across all weapons. The frontier and its choices
  are unchanged.
- Profile capabilities are explained as profile-wide information, rather than
  advertised as weapon coverage filters. Saved capability filters retain their
  behavior and now have a visible explanation and removal action.
- CSV loading rejects duplicate column names and duplicate reinforcement,
  attack-element, and passive keys
  instead of accepting ambiguous data.
- Extraction rejects fractional integer fields and non-finite numbers while
  preserving declared XML defaults and intentional optional fields.
- The mathematical reference limits its additive hit equation to routes admitted
  to the additive compiler; non-additive routes retain exact enumeration.

The optimizer architecture, runtime snapshots, and calculation model are unchanged.
This release does not certify additional game mechanics or Convergence behavior.

## Verification

Regression checks cover flat and varying chart scales, saved capability filters,
tradeoff scope, malformed CSV input, and extraction number handling. Release
packaging verifies the portable executable, MSI payload, startup, and checksums.
The published build report records the source commit and actual signing status.

Local checks passed: 205 core tests, 35 backend tests, 92 frontend unit tests,
65 browser tests, and 64 Python tests, plus Rust/Python lint, Python types,
the frontend production build, release metadata, and both snapshot validators.
The existing 5 benchmark-only Rust tests remain ignored in normal test runs.
Source-XML comparisons against v0.14.0 preserve reinforcement, attack-element,
and curve outputs for both profiles, along with all 8,382 source weapon curve-ID
mappings. This is a parser compatibility check, not a new in-game formula check.
