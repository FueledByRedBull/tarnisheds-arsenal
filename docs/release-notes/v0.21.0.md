# Release v0.21.0

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.21.0/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.21.0/docs/release-notes/README.md)

Tarnished's Arsenal now runs on Linux, with `.deb`, `.rpm` and AppImage packages.
Windows behavior and search results are unchanged.

## Linux

- **Debian and Ubuntu:** install the `.deb`. Your package manager pulls in WebKitGTK.
- **Fedora and openSUSE:** install the `.rpm`. Your package manager pulls in WebKitGTK.
- **Other distributions:** make the AppImage executable and run it.
- Linux builds use the same optimizer and the same bundled Vanilla and Convergence
  data as Windows.

Linux support is new. Each `.deb` and AppImage is tested on Ubuntu 24.04 with a search
in both profiles, on a virtual display with no graphics card, and has not been tried
on a physical Linux desktop or on other distributions. The `.rpm` is built but has not
been installed or launched. Please report anything that looks wrong through
**Report a problem** in the app.

## Data compatibility and limits

The bundled datasets are still **`vanilla-1.17.2`** and **`convergence-3.0.3.0-r2`**,
with snapshot schema **6** and runtime model **`aow-routes-effects-v9/exact-v3`**.
Saved builds and presets carry over unchanged on Windows. Convergence remains
experimental, as described in the
[v0.20.0 notes](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.21.0/docs/release-notes/v0.20.0.md).

Release packages are not code-signed.
