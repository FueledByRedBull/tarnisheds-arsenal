# Release v0.5.0

GitHub release: [Tarnished's Arsenal v0.5.0](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.5.0)

- Speed up medium and broad optimizer searches by lowering the Rust parallel-search threshold and balancing parallel work across individual Ash of War choices.
- Defer full ranking-row construction until after score-only candidates survive local top-K pruning, reducing hot-path cloning and metric completion work.
- Keep open weapon searches focused by returning only the best result per weapon, while preserving multiple loadout rows when a specific weapon is selected.
- Add Rust coverage for parallel work splitting, score-only top-K tie retention, loadout replacement, cancellation/progress behavior, and open-versus-locked weapon result grouping.
