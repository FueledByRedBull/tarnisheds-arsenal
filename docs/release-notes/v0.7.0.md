# Release v0.7.0

GitHub release: [Tarnished's Arsenal v0.7.0](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.7.0)

- Rebuild Ash of War damage around legal, ordered routes so mutually exclusive
  branches and finishers are never summed into one impossible sequence.
- Implement added base attack, status motion values, weapon-buff activation timing,
  action-level stamina, reinforcement scaling, and resolved physical hit attributes.
- Replace name-prefix buff inference with a numeric PARAM effect graph and explicit
  roles for persistent, per-hit, projectile, replacement, visual, and unsupported
  effects.
- Resolve fixed native skills deterministically, classify every missing passive
  source, and emit machine-readable attack/effect/passive coverage reports.
- Exclude 42 NPC rows and 15 unavailable affinity configurations from ranking.
- Make runtime data a checksummed, all-or-nothing snapshot and make extraction build,
  validate, and promote a staging snapshot with the manifest installed last.
- Harden Search, Compare, Paths, Affinity Watch, profiles, polling, cancellation, and
  shared analysis caches against stale or abandoned asynchronous work.
- Add selected-route details to Inspector, Compare, and CSV export while preserving
  compact ranking rows and existing scalar result fields.
- Add real packaged-data Tauri command tests, strict release gates, frontend race and
  polling tests, corruption tests, and reproducible non-browser calculator checks.
- Update the frontend lockfile to Vite 8.1.4 after resolving two Windows development
  server advisories; production and full `npm audit` now report zero vulnerabilities.

See [the v0.7.0 correction report](../validation/v0.7.0-correction-report.md) for
coverage counts, ranking-impact categories, and independent AR comparisons.
