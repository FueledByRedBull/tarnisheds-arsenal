# Release v0.12.0

v0.12.0 corrects loadout legality and starting-class selection, strengthens profile
validation, and prepares release documentation before packaging and publication.

- Correct Ash mounting permissions, native-only skills, extended affinity defaults,
  and all-affinity catalog IDs. Native skills cannot bypass infusion restrictions.
- Use snapshot schema 4 and compact compatibility permissions. Remove the redundant
  pair tables while testing compact permissions against the extracted rules.
- Share primary optimizer work across equivalent Ash choices without dropping
  ranking ties; preserve measured result fingerprints.
- Show actual fixed skill names in both selectors and preserve restored Automatic
  choices. Cover delayed responses and mount behavior in browser tests.
- Optimize starting classes against all eight entered stats without redistributing
  the target. Explain equal-budget Compare and Affinity Watch semantics in the UI.
- Reject invalid Path modes and propagate unknown weapon requirements as errors.
- Keep Convergence experimental and require exact entered stats until its class
  budgets are verified. Honor +15 upgrades for its verified Somber weapon types.
- Reject partially modeled skill damage candidates and cache reusable scalar
  routes. The measured open Max AR case improved by 16.9% with identical results.
- Validate MSI version and payload while preserving Tauri's distinct portable/MSI
  markers. Sign the installer executable after the marker patch. Publish the tag,
  binaries, and precommitted release documentation in one workflow run.

Raw model outputs do not include enemy defense, status proc damage, or universal
buff stacking. No-respec Paths retains its explicitly labeled greedy progression.
Convergence mechanics remain experimental; see the profile limits in the README.
