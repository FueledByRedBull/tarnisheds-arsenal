# Release v0.10.0

GitHub release: [Tarnished's Arsenal v0.10.0](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.10.0)

v0.10.0 is a behavior-preserving architecture and performance release. It removes
duplicate execution paths and reproducible repository artifacts while keeping
optimizer result ordering, data formats, cancellation, and the v0.9.3 interface
unchanged.

> **Convergence coverage remains beta; v0.10.0 is a stable application release.**
> Melee weapon AR, status, passives, affinities, compatibility, and extended grades
> remain supported for Convergence 3.0.0.1. Ammunition weapon AR and Convergence
> Ash of War hit/route damage remain disabled until their profile-specific models
> are validated.

- Make browser-mode tests use the same asynchronous start/status/cancel job shape
  as native Search, Paths, and Affinity Watch, then remove the synchronous forks.
- Route Search through one orchestration path and one typed polling hook while
  retaining exact request identity, cancellation, cleanup, and stale-result guards.
- Remove unused weapon-scaling and search-estimate APIs, dead helpers, redundant DTO
  tests, and `@tanstack/react-table`.
- Move weapon-type display normalization to the Rust core and reuse it from native
  callers.
- Derive affinity/scaling diagnostics during validation instead of tracking four
  reproducible CSVs; snapshot generation and promotion remove stale unlisted CSVs.
- Remove the internal PyO3/Maturin bridge and duplicate Python runtime suite. Rust
  remains the single calculation implementation, with native tests, release-mode
  phase benchmarks, and a narrow JSON probe for optional calculator comparisons.
- Fold duplicate Kinetic Forge overrides into the canonical stylesheet and remove
  dead selector families without changing the shipped layout.
- Score Max AR + Bleed with an exact bleed-only calculator during broad search;
  calculate AR and all statuses only for tie-breaking and retained results.
- Keep deterministic vector top-K maintenance after measurement showed a heap
  rewrite would target only about 4–6 ms even at 500 retained export rows.
- Replace brittle source-text release checks with executable clean-source,
  exact-commit, artifact, checksum, provenance, packaged-smoke, and optional signing
  gates.
- Fix Windows executable metadata so Explorer displays `Tarnished’s Arsenal`
  without a literal backslash before the apostrophe.

## Changes carried from v0.9.3

The v0.9.3 interface patch was not published separately. Its changes shipped in
v0.10.0 and did not change optimizer calculations or public data formats.

- Make Paths fit up to 200 displayed levels inside the available panel width
  without clipping or page-level horizontal overflow.
- Scale Paths and Affinity Watch to a padded observed metric range so meaningful
  gains remain visible instead of being visually compressed against zero.
- Replace Affinity Watch's duplicate bar treatment with a responsive multi-series
  crossover-line chart, distinct affinity colors, exact crossover markers, metric
  bounds, and a retained screen-reader table.
- Give Paths and Affinity Watch headers and content groups more breathing room.
- Use one centered sizing grid for Physical, Magic, Fire, Lightning, Holy, and all
  seven status tokens so badges do not shift between rows.
- Give populated and empty top-three cards the same internal inset; ranks and empty
  copy no longer sit against card borders.
- Add focused metric-domain tests and frontend-contract regressions for 90-level
  chart overflow, distinct Affinity rendering, badge widths, and empty-card insets.
