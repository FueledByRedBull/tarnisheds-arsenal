# Release v0.18.0

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.18.0/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.18.0/docs/release-notes/README.md)

Much faster searches with the same results, a calmer screen that keeps rare
controls one click away, and analyses that survive switching tabs.

## Speed

- Searches return the same ranked builds much sooner. On the measured desktop, an
  open Ash of War search at level 150 takes about 64 ms instead of 6.5 s, an
  all-upgrades bleed search at level 93 takes 86 ms instead of 2.4 s, and Affinity
  Watch over 200 levels with any Ash takes 0.16 to 0.23 s instead of 2.45 s. Lifesteal Fist
  searches are 10 to 15 times faster, such as an all-upgrades level 60 search in
  1.9 s instead of 28 s.
- Exact bounds now skip setups that cannot reach the current top results, and
  Affinity Watch calculates its affinities at the same time. On the same data,
  the ranking, its tie order, and every value are unchanged.
- **Cancel** stops a search at its next check instead of after its next progress
  update.
- Scrolling, sorting, typing, popovers, and tab switching hold 144 fps in the
  measured interactions, including while a long search runs. **Ctrl+1** to
  **Ctrl+4** respond in under 8 ms instead of about 25 ms, and the first Compare
  visit opens in about 6 ms instead of 30 ms. Resizing the window and opening the
  shortcuts list can still take one or two longer frames.

See the performance measurements for the
[searches](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.18.0/docs/performance.md#search-pruning-pass-2026-10-17)
and the
[frame pacing](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.18.0/docs/performance.md#frame-pacing-2026-10-17)
for methods and limits.

## Desktop

- The query line reads class, objective, loadout, upgrades. Scadutree blessing,
  result count and grouping, and stat locks and minimums share one
  **More options** part that names only the settings you changed.
- The loadout editor starts with the weapon, and the Standard or Somber filter is
  three buttons instead of a dropdown.
- Rankings replaces the always-open metric glossary with a **Columns** guide, and
  **Export CSV** asks for the row count when you export.
- Build Detail keeps the answer on top and folds weapon poise, the stat budget,
  and model notes into **More details**.
- Compare, Paths, Affinity Watch, and AR / Bleed tradeoffs share one heading with a
  **How it works** link for their rules, and lose most of their boxed panels.
  Chart values sit in a **Data table** you open on demand.
- Skill damage that the current results do not model is left out instead of
  shown as Unavailable, and healthy states no longer announce themselves on
  screen.
- Text uses seven sizes with a 12 px minimum. Rankings is one keyboard stop with
  arrow keys inside it, and reduced motion keeps fades while dropping movement.
- The app remembers each profile's query across restarts and restores it when you
  return to that profile.

## Fixes

- Switching workspaces no longer cancels a running Paths, Affinity Watch, or
  AR / Bleed tradeoffs analysis. Only changing its inputs does.
- Leaving Rankings cancels a running CSV export.
- Pressing **Enter** in a searchable list, such as the skill picker, keeps the
  current choice instead of resetting it.
- Saved builds, backups, and imported builds keep only the fields the app knows;
  unknown fields are dropped instead of carried into later saves.
- Black Steel Greathammer and Hookclaws skill poise values now include the game's
  weapon poise data.
- If the app cannot start, for example because WebView2 is missing, it shows a
  message instead of closing silently. Browser reload and print shortcuts no
  longer reload or print the app window, on any keyboard layout.

## Data compatibility and limits

Both snapshots are regenerated from the same game and mod sources as
**`vanilla-1.17-r3`** and **`convergence-3.0.0.1-r3`**, with every value written at
full `f32` precision. The 19 measured searches return the same builds in the
same order; exact ranking keys moved by at most 0.000054, and a few values changed
in their last displayed digit. Snapshot schema **6** and runtime model
**`aow-routes-effects-v9/exact-v3`** are unchanged. The game profiles remain
Vanilla **1.17** and Convergence **3.0.0.1**. Convergence retains its documented
experimental feature limits.

Builds and comparison pins saved with v0.17.x name the earlier datasets, so they
are recomputed on the new data when loaded, with their saved weapon, affinity,
skill, upgrade and stats; numbers may differ very slightly from what was saved.
Pins inside a saved build use that build's saved query, so they match their
original setup. Standalone pins kept by Compare store no query, so they are
recomputed with your current class, two-handing, Scadutree blessing and DLC
scaling settings. The saved build record is not changed. A build or pin that
cannot be recomputed loads its inputs only, or for a pin is removed, and the app
says so.

AR and status values do not include enemy defenses, resistance growth, or status
proc damage. Sequence totals assume the modeled contacts connect. War Cry and
Barbaric Roar's attack-power self-buffs are not modeled. This release does not
claim live in-game verification of every skill.

## Verification

The release source passed 253 core tests, 65 backend tests, 255 frontend unit
tests, 34 Node contract checks, the production frontend build, 161 Python
extraction and validation-tool tests, Ruff, and release metadata validation;
release-mode benchmarks, which are opt-in, were not part of this run. The branch's
final integration run before the version bump also passed 189 browser tests,
frontend lint, Clippy and formatting for both Rust crates, Pyright, the snapshot
validator, 7 native-responsiveness metric tests, and the packaged WebView2 smoke
test, which now checks that analyses survive tab switches. CI repeats these gates
on the release commit.

The search speedups were checked against the previous optimizer by complete ranked
results: every benchmark case in both profiles at default and one thread, 400
seeded random requests across both profiles, all objectives, levels 9 to 713,
upgrade modes, locks, and level ranges, 3,335 Lifesteal Fist cases, and every
Affinity Watch, Paths, and native command payload matched. A seeded external
reference comparison against the pinned T. Clark 1.17 calculator passed all 632
Vanilla weapon AR and base status cases on the r3 data, and the exhaustive
raw-data check passed for both profiles. Neither check verifies skill damage
formulas.

Timings were measured on one Windows desktop with a 240 Hz display while other
work shared the CPU; the performance measurements record their methods and
variation. Versioned packages must pass the release workflow's package checks
before publication. Installation, upgrade, and uninstall on a clean Windows
machine were not exercised. Release packages are not code-signed; the build
report records the final source commit, package checks, and signing status.
