# Release v0.3.3

GitHub release: [Tarnished's Arsenal v0.3.3](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.3.3)

## What's New

- Formalized status-scaling gates from the workbook `SpEffectParam` data via `isUseStatusAilmentAtkPowerCorrect`.
- Added per-status correction flags to `weapon_passives.csv` and `aow_buffs.csv`.
- Runtime status scaling now uses those flags as the primary gate instead of relying only on hardcoded status-family heuristics.
- Kept the previous heuristic as a fallback when the workbook does not expose the source passive effect row, so known passive cases do not regress.
- Updated validation to enforce the new status-correction columns and Seppuku flag coverage.
- Updated README to document the runtime behavior accurately.

## Included In This Release

- Updated desktop app bundle
- Updated Rust core extension
- Refreshed phase-1 CSV snapshot
