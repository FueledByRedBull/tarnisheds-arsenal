# Release v0.19.0

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.19.0/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.19.0/docs/release-notes/README.md)

Game data for Elden Ring 1.17.2 and The Convergence 3.0.3.0, much faster Paths and
Affinity Watch, old saved builds that open again, and Cancel that stops every queued
search.

## Speed

- Searches over a range of levels, which Paths and Affinity Watch run, return the
  same results much sooner. An open Ash of War search over levels 80 to 130 with
  every upgrade takes about 0.28 s instead of 3.4 s, and 1.3 s instead of 21 s on
  one thread.
- Single searches are a little faster too: an open Ash of War search takes about
  62 ms instead of 74 ms at level 80, and 80 ms instead of 99 ms at level 150.
- New results appear in **Rankings** without a long frame: when 50 rows land, the
  longest frame is about 8 ms instead of 12 to 17 ms, and the first results after
  launch take 13 to 17 ms instead of 38 to 42 ms. The board looks the same as before.

See the performance measurements for the
[level ranges](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.19.0/docs/performance.md#shared-level-ranges-2026-10-21)
and the
[result landing](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.19.0/docs/performance.md#result-landing-2026-10-21)
for methods and limits.

## Game data

- Vanilla now matches Elden Ring **1.17.2** (regulation 1.17.3). The patch changed
  one value the app reads, the Fletched Piquebone Arrow projectile's attack link,
  and every table the app uses is unchanged, so Vanilla results are the same as in
  v0.18.0.
- Convergence now matches the mod's **3.0.3.0** release, which is built on game
  version 1.17.1. It has 3,305 weapon configurations instead of 3,189:
  - New weapons include Dual Katana, Halberd of the Deceiver and Huntress's Estoc,
    and 1.17's Golden Order Flail, Ritual Thrusting Shield and Silver Grooved Shield
    are now in the mod.
  - The mod's Greatsword of Midra, Demi-Dragon Cleaver, Eagle's Edge, Fingerslayer
    Blade and Sword of the Cosmos moved to new IDs. Their old IDs now hold 1.17's
    Leontiel's Greatsword, Hefty Scimitar, Reed Great Katana, Reverse-Bladed Sword
    and Idus Sword.
  - Apart from those reused IDs, 109 configurations changed. Gaelor's Mancatcher is
    now spelled Gaoler's Mancatcher, 42 weapon skills gained a name, 18 weapons can
    now take an Ash of War, and others changed holy damage, status curves or attack
    element rows. Nineteen Ashes of War that showed a weapon skill's name now show
    their own, such as Flame of the Redmanes (`505`) and Glintblade Phalanx (`200`);
    those skills, such as Aeonian Rush, are now the weapons' own.
  - There are 29 starting classes instead of 27. The two new ones, named
    "Retainer Alt (Tarnished Edition)" and "Dreadnought Alt (Tarnished Edition)" in
    the mod's data, have Retainer's and Dreadnought's stats, and Glint Sorcerer is
    now first in the list.

## Fixes

- Builds saved with v0.7 to v0.10 that have a skill route open again: **Load** works,
  **Export all builds** includes them, and re-importing one with **Keep both** or
  **Replace matching ID** no longer fails.
- **Update selected** no longer overwrites a build saved in the other profile with
  this profile's data; it says to switch profile or use **Save new**.
- Restoring a backup that holds a build over the per-build size limit is refused
  before anything is written, and names that build, instead of restoring a build
  that could not be renamed or updated afterwards.
- Recovering saved builds now works when browser storage is nearly full, and says
  plainly when it cannot, without changing your builds.
- Exported CSV files open correctly in Excel: names such as Miséricorde no longer
  turn into garbled characters.
- **Cancel** now stops a search that is still waiting to start, whether it came
  from **Run updated search**, **Lock** or the **L** key, or the starter example.
- In Convergence, locking a Somber result keeps the profile's single upgrade cap,
  so the search and the query line agree (a search could run at `+12` while the
  line said `+15`).
- Switching profile with a class both profiles share, such as Prisoner, starts from
  the new profile's class stats instead of failing with "below class minimums".
- The fixed-stats readout no longer says "Convergence" in Vanilla.
- Compare's upgrade matrix no longer scrolls smoothly when reduced motion is on.
- At startup, the weapon details no longer stay stuck on "Weapon profile
  unavailable" when the catalog arrives before the restored weapon.
- Loading a saved build without pins no longer stalls while older pins are
  recalculated.
- A failed Paths run now shows as failed, not cancelled.
- The stat budget no longer shows an unspent count that was always zero.
- The Experimental model note names the Convergence mod and game versions.

## Data safety

- The app refuses to load game data written by an unknown extractor or model
  version, and data in which a weapon has no status row, instead of showing 0
  buildup for it.
- Extraction compares every Ash of War and weapon skill attack value taken from the
  motion workbook with the game's own attack parameters and stops on any
  difference, so a patch that changes skill damage cannot ship stale values.
- Validation checks that each bundled dataset was extracted from the exact game or
  mod file its profile pins.
- The Scadutree blessing multipliers now come from the same table the calculations
  use, bow and crossbow rules use weapon type IDs instead of names, and analyses
  find the selected weapon by its ID.
- Pasting different import text after choosing **Replace matching ID** returns the
  choice to **Keep both (safe copy)**, so it cannot overwrite a build the new text
  was not meant to replace.
- Loading refuses data with a repeated skill attack or route row instead of
  counting that hit twice.
- Extraction refuses to write over another profile's dataset.

## Data compatibility and limits

The bundled datasets are **`vanilla-1.17.2`** and **`convergence-3.0.3.0`**. Snapshot
schema **6** and runtime model **`aow-routes-effects-v9/exact-v3`** are unchanged.

Builds and comparison pins saved with v0.18.x name the earlier datasets, so they are
recomputed on the new data when loaded, with their saved weapon, affinity, skill,
upgrade and stats. Vanilla values come out the same. Convergence values follow the
mod's changes. A Convergence build whose weapon moved to a new ID, or whose weapon
or skill name changed in 3.0.3.0, cannot be recomputed with its saved equipment, so
it loads its inputs only and the app says so; the saved record is not changed.

Convergence remains experimental with its documented limits: no Ash of War damage
or ammunition AR, fixed status buildup, and upgrades to `+15` on one shared cap.
Class names are the mod's own data names; the menu text the game shows for them is
not an extraction input.

AR and status values do not include enemy defenses, resistance growth, or status
proc damage. Sequence totals assume the modeled contacts connect. War Cry and
Barbaric Roar's attack-power self-buffs are not modeled. This release does not
claim live in-game verification of every skill.

## Verification

The release source passed 264 core tests, 72 backend tests, 268 frontend unit tests,
35 Node contract checks, 202 browser tests, frontend lint and the production build,
176 Python extraction and validation-tool tests, Ruff, Pyright, the snapshot
validator, Clippy and formatting for both Rust crates, and the packaged WebView2 smoke
test. CI repeats these gates on the release commit.

The level-range changes were checked by comparing complete results with the code
before them: the 51-level range at the default thread count and on one thread, and 1,400
seeded random requests across both profiles, every objective and 643 level ranges.
All matched, including the requests both builds refuse. Every **Rankings**
screenshot taken after results land matched the earlier build pixel for pixel.

A seeded comparison with the pinned T. Clark calculator passed all 632 Vanilla weapon
AR and base status cases on `vanilla-1.17.2`. The 600 Convergence cases ran against
the calculator's own data build, run on the mod's 3.0.3.0 files because the calculator
publishes no data past 3.0.0.1, and all matched AR within 0.0002 per component. The
exhaustive raw-data check passed for both profiles: 87,879 Vanilla and 154,318
Convergence weapon and Ash pairs, plus 3,197 and 3,200 native pairs. Neither check
verifies skill damage formulas.

Timings come from one Windows desktop with a 240 Hz display; the performance
measurements record their methods and spread. Versioned packages must pass the
release workflow's package checks before publication. Installation, upgrade and
uninstall on a clean Windows machine were not exercised. Release packages are not
code-signed; the build report records the source commit, package checks and signing
status.
