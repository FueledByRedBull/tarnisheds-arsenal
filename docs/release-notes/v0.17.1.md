# Release v0.17.1

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.1/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.1/docs/release-notes/README.md)

The top result says why it is first, Build Detail and Compare are less crowded,
and keyboard and screen-reader gaps are closed.

## Build Detail

- Build Detail says how far #1 leads #2, how many legal setups the exact ranking
  covers, and which of your entered stats the build changes. A small setup count
  shows at once that stat locks or filters have narrowed the search.
- **Why this build?** names the runner-up and the largest AR difference behind
  the lead.
- The header stays in view while the details scroll and carries the ranked number
  once it sticks.
- Saved Builds and **Report a problem** fold under Build Detail and open on
  demand. **Save build** opens Saved Builds, a library error opens it so the alert
  stays visible, and an unnamed save takes the build's name, such as
  "Blood Uchigatana +25".
- Status tiles show only the statuses the build inflicts.

## Workspaces

- Compare folds its build cards and drops the prose list that repeated the delta
  table.
- Every disabled workspace tab looks disabled, and the reason is printed beside
  the tab bar. Compare shows how many builds are pinned.
- Each profile keeps its query and restores it when you switch back. Results are
  searched again on demand, and a query is never carried into another profile.
- CSV export takes its row count from a menu beside **Export CSV**.
- A skill column that would read Unavailable on every row, as in Convergence,
  becomes one note in the header.
- `level N` in the **Ctrl+K** palette plans those levels in Paths.

## Keyboard and screen readers

- Ranked rows announce their AR or score. **P** pins and **L** locks the focused
  row, and the row buttons leave the tab order, so 25 rows are 25 tab stops
  instead of 75.
- Notices sit in one live region and no longer replay their entrance when a newer
  one arrives.
- Field borders reach 3:1 contrast, small text is 12 px, and explanations that
  were only tooltips are also exposed to screen readers.

## Polish

- The **Ctrl+K** palette opens without motion, and **Ctrl+1** to **Ctrl+4** switch
  workspaces with a 140 ms fade.
- Lock wording is unified as "stat locks", Movable becomes Respec, objectives
  describe what they rank by, and headings use Windows' Sitka typeface.
- The query line stays on one row at 1366 px.
- The unused background texture is removed and the brand mark shrinks from 74 KB
  to 5 KB.

## Data compatibility and limits

The optimizer, the bundled data, and the scoring model are unchanged: snapshot
schema **6** and runtime model **`aow-routes-effects-v9/exact-v3`**, so builds
saved with v0.17.0 load with their results. The game profiles remain Vanilla
**1.17** and Convergence **3.0.0.1**. Convergence retains its documented
experimental feature limits.

AR and status values do not include enemy defenses, resistance growth, or status
proc damage. Sequence totals assume the modeled contacts connect. War Cry and
Barbaric Roar's attack-power self-buffs are not modeled. This release does not
claim live in-game verification of every skill.

## Verification

The release source passed 241 core tests, 61 backend tests, 205 frontend
unit tests, 166 browser tests, 17 Node contract checks, and 7
native-responsiveness metric tests; release-mode benchmarks, which are opt-in,
were not run. Frontend lint and the production build, Clippy and formatting for
the backend crate, 122 Python extraction and validation-tool tests, and release
metadata validation also passed. Five packaging tests that need PowerShell 7 were
skipped locally and run in CI, which also runs Clippy and formatting for both
Rust crates.

The release executable passed the packaged WebView2 smoke test with the version
bump. The optimizer and the bundled data are unchanged from v0.17.0, so the
external reference comparisons recorded in the
[v0.17.0 notes](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.1/docs/release-notes/v0.17.0.md#verification)
were not rerun.

Versioned packages must pass the release workflow's package checks before
publication. Installation, upgrade, and uninstall on a clean Windows machine were
not exercised. The release build report records the final source commit, package
checks, and signing status.
