# Release v0.17.2

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.2/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.2/docs/release-notes/README.md)

Fixes to what Build Detail and Rankings claim about a result, and to
profile switching.

## Fixes

- A saved build that is loaded on its own no longer reads "Rank 1 of 1 · best for
  this query". It was not ranked against anything, so Build Detail shows a rank
  only for search results.
- The setup count introduced in v0.17.1 is now described as what it is: "Ranked
  exactly across N scored setups", with the reason shown beside it: stat spreads
  that differ only in stats a setup doesn't use count once. The count can
  therefore be smaller than the number of legal allocations, and a count of one
  no longer claims to be the only legal setup. The ranking was and remains exact.
- Searching again with unchanged results no longer shows rank movement or damage
  changes when the same loadout is ranked at several upgrade levels. Rows are
  matched to the previous search by upgrade as well, and a loadout is followed
  across an upgrade change only when it is ranked once in both searches.
- **Why this build?** calls two builds tied at the displayed precision only when
  their values print the same. A visible gap smaller than 0.05, such as 100.1
  against 100.0, now reads "leads … by less than 0.05".
- Returning to a profile restores its query even when the profile you left it for
  failed to load, and **Retry loading** on a failed profile keeps the query you
  were editing. Before, equipment, objective, and stat locks were reset.

## Data compatibility and limits

The optimizer, the bundled data, and the scoring model are unchanged: snapshot
schema **6** and runtime model **`aow-routes-effects-v9/exact-v3`**, so builds
saved with v0.17.1 load with their results. The game profiles remain Vanilla
**1.17** and Convergence **3.0.0.1**. Convergence retains its documented
experimental feature limits.

AR and status values do not include enemy defenses, resistance growth, or status
proc damage. Sequence totals assume the modeled contacts connect. War Cry and
Barbaric Roar's attack-power self-buffs are not modeled. This release does not
claim live in-game verification of every skill.

## Verification

Each fix has a regression test. The release source passed 241 core tests, 61
backend tests, 209 frontend unit tests, 166 browser tests, 17 Node contract
checks, and 7 native-responsiveness metric tests; release-mode benchmarks, which
are opt-in, were not run. Frontend lint and the production build, formatting for
the backend crate, 122 Python extraction and validation-tool tests, and release
metadata validation also passed. Five packaging tests that need PowerShell 7 were
skipped locally and run in CI, which also runs Clippy and formatting for both
Rust crates.

The release executable passed the packaged WebView2 smoke test with the version
bump. The optimizer and the bundled data are unchanged from v0.17.0, so the
external reference comparisons recorded in the
[v0.17.0 notes](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.17.2/docs/release-notes/v0.17.0.md#verification)
were not rerun.

Versioned packages must pass the release workflow's package checks before
publication. Installation, upgrade, and uninstall on a clean Windows machine were
not exercised. The release build report records the final source commit, package
checks, and signing status.
