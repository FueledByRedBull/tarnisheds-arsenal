# Release v0.15.0

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.15.0/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.15.0/docs/release-notes/README.md)

Corrected weapon and skill calculations, faster searches, and more reliable saved
builds, comparisons, and progression previews.

## Calculations and performance

- Correct Bloodfiend's Fork bleed-floor boundaries, including the stat allocation
  that previously spent its last point on Strength instead of Arcane. All 32
  formerly failing cases are retained in external validation. Exact ranking,
  pruning, and tie ordering remain in place.
- Count source-marked repeated skill contacts, distinguish partial and charged
  routes, preserve fixed stance damage, and correct five Scadutree multipliers
  against regulation data.
- Share exact top-K cutoffs between parallel search workers and avoid repeated
  status and multi-hit calculations. Release builds use ThinLTO and one codegen
  unit. The runtime thread policy is unchanged; performance depends on the
  workload, and more threads do not always improve scoring time.
- Keep reusable evaluators correct when budgets increase, and honor cancellation
  even when a locked evaluation has no eligible weapons.

See the [model reference](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.15.0/docs/model-reference.md),
[optimizer mathematics](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.15.0/docs/design/optimizer-math.md),
and [performance measurements](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.15.0/docs/performance.md)
for formulas, sources, assumptions, and benchmark scope.

## Saved builds and workflows

- Recover damaged saved-build indexes while preserving the original data. Preview
  bulk backups and restore builds as copies; handle interrupted writes and denied
  storage access without making the interface unusable.
- Add previewable reproduction reports, calculated build explanations, and
  per-stat comparison differences. Compare every explicit pinned build, including
  unupgradeable weapons such as Meteorite Staff at +0.
- Prevent stale selections and late replies from updating analyses, exports, or a
  newer search. Preserve partial stat locks and reject malformed comparison pins,
  preset enums, and saved numeric values before import or recovery.
- Improve Paths charts with labeled axes, sparse markers, and a level-inspection
  slider. Add the Arsenal brand mark and a simplified Windows icon.
- Harden background jobs, cancellation, snapshot loading, and session recovery.
  Keep parallel progress updates in delivery order.

React and React DOM move to 19.3. Frontend checks now enforce React Hooks rules
and Rust/TypeScript message contracts. Production connections are restricted,
and package verification checks the ZIP executable against the portable binary.

## Data compatibility and limits

Both bundled profiles are regenerated with snapshot schema **6** and runtime model
**`aow-routes-effects-v8/exact-v2`**. Older solved results are invalidated so they
cannot be mistaken for results from the corrected model; saved inputs remain
reusable. The game profiles remain Vanilla **1.17** and Convergence **3.0.0.1**.
Convergence retains its documented experimental feature limits.

AR and status values do not include enemy defenses, resistance growth, or status
proc damage. Sequence totals assume the modeled contacts connect. Per-hit status
stacking and stamina costs for held skill loops remain unverified; this release
does not claim live in-game verification of every skill.

## Verification

The application changes passed 229 core tests plus the benchmark equivalence test,
56 backend tests, 139 frontend unit tests, 80 browser tests, and 17 Node contract
checks. Rust formatting and Clippy, frontend lint and production build, and both
snapshot validators also passed. Hosted
[CI passed on source commit 29c2559](https://github.com/FueledByRedBull/tarnisheds-arsenal/actions/runs/36252307282)
before the version and documentation preparation.

External reference comparisons passed **1,345,950 Vanilla** and **415,011
Convergence** weapon AR/status evaluations with zero failures at the documented
tolerances. A separate 33,462-case Bloodfiend's Fork sweep covered every affinity,
upgrade, and Arcane value, including numerical cases below weapon requirements.
Raw-data checks covered 2,654 attack rows, all 21 Scadutree multipliers, and all 15
explicit repeat annotations. Legal-pair sets matched their source tables.
These checks establish the stated numeric and data coverage, not independent
verification of every skill formula.

Release preparation also passed all 118 Python extraction and validation-tool
tests, synchronized version metadata validation, and documentation link checks.

The pre-version-bump production executable and extracted unsigned MSI payload
passed packaged WebView2 smoke checks. Those artifacts were labeled 0.14.1 and
are not v0.15.0 release packages. Versioned packages must pass the release
workflow's package checks before publication. Actual installation, upgrade, and
uninstall on a clean Windows machine were not exercised. The release build report
records the final source commit, package checks, and signing status.
