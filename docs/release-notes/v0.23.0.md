# Release v0.23.0

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.23.0/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.23.0/docs/release-notes/README.md)

Convergence now marks the right weapons as Somber, and searches and startup are faster.
Damage numbers and rankings are the same as in v0.22.0 in both profiles.

## Convergence

- Somber status now follows each weapon's upgrade cost. 44 weapons were marked wrong:
  40 regular weapons were labelled Somber, and 4 Somber weapons, such as the Aegis of
  Hadea, were not.
- Convergence uses one upgrade cap for every weapon, so the Smithing/Somber filter and the
  Somber tag are hidden in this profile.
- Saved builds on a reclassified weapon still load.

## Speed

- Level-range searches in Paths are much faster, most of all for skill objectives. A
  50-level Convergence range for a skill's first hit takes about a quarter of the time.
- Open Max AR searches and skill searches at high levels are faster.
- Both profiles load in parallel at startup.
- Selecting a row and opening the command palette for the first time take less work on
  the main thread, so frames are dropped less often.

## App

- Disabled controls explain why they are disabled, and number fields tell screen readers
  the value they settled on after clamping.
- A search with no results shows a message instead of an empty table.
- If a workspace or the Build Detail panel hits an error, it recovers when you switch
  workspace, profile or selection, without a restart.
- The saved-build name field follows the selected build, so **Update selected** can no
  longer write another build's name over it. Exporting a build says where the file went.
- Restoring a saved query keeps its coverage filters.
- One damaged pin in a saved Compare bench no longer pushes out a valid one.
- Each Affinity Watch line has its own dash pattern, so lines can be told apart without
  color.
- Some labels are clearer, such as **No skill**, **Any weapon** and **Max Physical AR**.

## Security

- The app rejects oversized text in requests to its native side and no longer repeats
  rejected text in error messages.
- The app window cannot navigate to other sites, and the content security policy blocks
  form submission.

## Data compatibility and limits

The bundled datasets are **`vanilla-1.17.2`** and **`convergence-3.0.3.0-r4`**, with
snapshot schema **6** and runtime model **`aow-routes-effects-v9/exact-v3`**. The
Convergence snapshot changes only which weapons are Somber. Saved builds and comparison
pins from earlier versions load, and their numbers do not change.

Convergence remains experimental: none of its values are measured in game. Hold-to-repeat
loops and bow skills stay unmodeled, some conditional status effects are not counted, and
about 1,000 weapon and Ash pairs whose hits differ from the rest of their weapon type use
their type's hits. Ammunition AR is unavailable.

The `.deb`, AppImage and `.rpm` are tested on a virtual display, on Ubuntu 24.04 for the
first two and Fedora for the `.rpm`, and have not been tried on a physical Linux desktop.
Release packages are not code-signed.
