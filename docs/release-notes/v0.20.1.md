# Release v0.20.1

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.20.1/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.20.1/docs/release-notes/README.md)

Clearer button names for screen readers and voice control, and updated dependencies.
Search results are unchanged.

## Accessibility

- Buttons now include their visible text in the name assistive technology reads out,
  so saying what you see on a button works with voice control.
- The Rankings **Columns** button is now labeled **Column guide**.
- **How it works** buttons announce both that text and the topic, such as
  "How it works: About Compare".
- The Build Detail compare button announces its visible text and the weapon, such as
  "Pin for compare: Uchigatana".
- The Weapon Type, Affinity and Compare filter buttons announce their current value
  along with their label.

## Dependencies

- Tauri 2.12.4 and its matching JavaScript packages.
- brotli-decompressor 6, serde_json 1.0.154, and newer versions of the tools used to
  build and check the app.

## Data compatibility and limits

The bundled datasets are still **`vanilla-1.17.2`** and **`convergence-3.0.3.0-r2`**,
with snapshot schema **6** and runtime model **`aow-routes-effects-v9/exact-v3`**.
Saved builds and presets carry over unchanged. Convergence remains experimental, as
described in the [v0.20.0 notes](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.20.1/docs/release-notes/v0.20.0.md).

This release is for Windows only. The source now includes Linux packaging settings,
but no Linux package is built or published, and Linux has not been tested. Release
packages are not code-signed.
