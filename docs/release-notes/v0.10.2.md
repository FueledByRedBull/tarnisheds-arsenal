# Release v0.10.2

GitHub release: [Tarnished's Arsenal v0.10.2](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.10.2)

v0.10.2 is a performance, maintainability, and documentation patch for v0.10.1.

> **Convergence coverage remains beta; v0.10.2 is a stable application release.**
> Its verified model coverage is unchanged from v0.10.1.

- Restrict `Bleed, then AR` relevance to stats that can actually affect bleed or
  AR under the active profile. A pinned Erdsteel Dagger/Poison case drops from
  22,100 candidates to 1,275 while preserving exact results.
- Align status-overlay relevance with the calculation path and add regression
  coverage for both Vanilla and Convergence status-scaling rules.
- Document the optimizer's exactness boundary, formula provenance, arbitrary
  curve handling, two-handed Strength behavior, and final-value recomputation.
- Simplify browser fixtures while preserving the native asynchronous job contract
  and the complete end-to-end UI flows.
- Reuse adaptive polling for exports and remove retired iterator code, tautological
  DTO tests, dead CSS, duplicate changelog content, and a stale phase report.
- Keep all bundled data snapshots and Convergence model coverage unchanged.
