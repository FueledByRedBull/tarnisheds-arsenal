# Release v0.4.7

GitHub release: [Tarnished's Arsenal v0.4.7](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.4.7)

- Add Rayon-backed parallel optimizer search for broad weapon and Ash of War runs while preserving serial behavior for small searches.
- Redesign optimizer progress and cancellation around batched atomic updates, time-throttled snapshots, and polling-based Tauri status.
- Precompute Tauri-side catalog indexes for weapon, affinity, type, compatibility, requirement, and upgrade-cap lookups.
- Batch independent Compare view requests so rival solves and lane detail calls run concurrently without changing displayed results.
- Move zero-base AR rejection earlier in the Rust math path to skip unnecessary curve and scaling work.
- Keep the archived PyQt UI untouched; this release targets the active Rust, Tauri, and TypeScript desktop app.
