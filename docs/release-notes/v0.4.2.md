# Release v0.4.2

GitHub release: [Tarnished's Arsenal v0.4.2](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.4.2)

- Promote the Tauri desktop UI to the primary packaging target while keeping PyQt as a legacy/reference UI.
- Add Tauri session parity for derived level, result locks, compare, paths, affinity watch, and production-only local data loading.
- Fix unlocked Ash of War search for `Max AR` and `Max AR + Bleed`.
- Fix bleed-objective metric propagation across compare, paths, affinity watch, and upgrade series.
- Surface optimizer failures in the desktop UI instead of silently treating them as empty results.
- Clean up duplicated desktop path and affinity helper code.
