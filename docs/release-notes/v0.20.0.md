# Release v0.20.0

[Home](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.20.0/README.md) · [All releases](https://github.com/FueledByRedBull/tarnisheds-arsenal/blob/v0.20.0/docs/release-notes/README.md)

Ash of War damage and routes for The Convergence, and Convergence class names as the
game shows them.

## Convergence

- **AoW First Hit** and **AoW Full Sequence** now work in Convergence. Each weapon's
  hits come from the mod's own skill animations and scripts, picked the way the game
  picks them, with values from the mod's attack parameters. 90 of the 122 Ashes of
  War deal damage, and 12 more only apply an effect. Of the weapon skills, 398 have
  hits of their own and 2,873 use the hits of the Ash of War the weapon carries.
- Skills the animations alone do not define are left out and listed in the
  extraction diagnostics: bow skills, which depend on the equipped arrow, buff states,
  hold-to-repeat loops, bullets spawned on a timer, and the left-hand shield skills.
  Kick has no hits in the mod's animations.
- Class names now match the character-creation screen: **Stormcaller**,
  **Retainer (Alt)** and **Dreadnought (Alt)** replace the mod's data names Storm
  Caller, Retainer Alt (Tarnished Edition) and Dreadnought Alt (Tarnished Edition).
  Saved builds and the restored session that use the old names load under the new
  ones and keep their stats.
- Weapon skills the mod leaves unnamed now show no name, instead of a number such as
  "5111" on the Velvet Sword of St. Trina.
- The **Experimental model** label stays in the header for Convergence now that it
  has skill damage.

## Speed

- Searches prepare their Ash of War choices with less repeated work. Every Vanilla
  benchmark search returns the same results as before, most of them faster: an open
  Max AR search takes about 127 ms instead of 140 ms on one thread, and an open AoW
  Full Sequence search about 354 ms instead of 392 ms.
- Convergence searches now score skill damage too, and that takes time. On one
  thread, an open Max AR search at a high level takes about 204 ms, against 173 ms
  in v0.19.0, when Convergence had no skill data. Open AoW searches in Convergence
  cover a much larger stat space than in Vanilla, because the mod lets every stat
  scale every damage type; with all threads they take about 0.16 to 0.2 s.

## Data compatibility and limits

The bundled datasets are **`vanilla-1.17.2`** and **`convergence-3.0.3.0-r2`**.
Snapshot schema **6** and runtime model **`aow-routes-effects-v9/exact-v3`** are
unchanged, and Vanilla data is identical to v0.19.0.

Convergence builds and comparison pins saved with v0.19.0 name the earlier dataset,
so they are recomputed on the new data when loaded, with their saved weapon,
affinity, skill, upgrade and stats.

Convergence remains experimental. Its skill damage has no independent reference:
Vanilla's own animation files sit in the game's encrypted archives, so the
animation reader has not been compared with the Vanilla workbook, and no skill
value is measured in game. Ammunition AR is unavailable, status buildup is fixed,
and upgrades go to `+15` on one shared cap.

AR and status values do not include enemy defenses, resistance growth, or status
proc damage. Sequence totals assume the modeled contacts connect.

## Verification

The release source passed 265 core tests, 72 backend tests, 270 frontend unit tests,
35 Node contract checks, 202 browser tests, frontend lint and the production build,
188 Python extraction and validation-tool tests, Ruff, Pyright, the snapshot
validator, and Clippy and formatting for the core crate. CI repeats these gates and
the packaged smoke test on the release commit.

Regenerating the Convergence snapshot twice produced identical files. A seeded
comparison with the pinned T. Clark calculator on `convergence-3.0.3.0-r2` matched
all 600 weapon AR cases within 0.0002 per component, all 600 base status cases, and
the selected skill for all 294 cases that have one; it does not check skill damage.
Vanilla data is byte-identical to v0.19.0.

The speed figures are medians of five runs on one Windows desktop, with the builds
being compared run alternately; the faster preparation was checked to return the
same ranked results in every benchmark search. Release packages are not
code-signed; the build report records the source commit, package checks and signing
status.
