# Release v0.3.0

GitHub release: [Tarnished's Arsenal v0.3.0](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.3.0)

This release pushes the desktop app further into a single session-driven analysis hub.

Highlights since v0.2.0:
- Added a canonical desktop state model with `GlobalSession`, `SolvedBuild`, and a dedicated optimizer service layer.
- Rewired the desktop UI so rankings, compare, paths, and affinity-watch all derive from the same active session and selected solution.
- Upgraded `PATHS` and `AFFINITY WATCH` from dialog-style tools into embedded workspaces with live status, charts, and tables.
- Preserved selection across compatible reruns using solved-build fingerprints instead of fragile row state.
- Added shared worker lifecycle handling so search and analysis flows no longer each own separate thread plumbing.
- Fixed release packaging for the refactor by shipping the desktop module set, not just `app.py`.
- Rewrote the README around the real product model, objectives, workflows, and release/build paths.

Included asset:
- Windows x64 standalone build (`TarnishedsArsenal.exe`) with bundled runtime data.

Full Changelog: https://github.com/FueledByRedBull/tarnisheds-arsenal/compare/v0.2.0...v0.3.0
