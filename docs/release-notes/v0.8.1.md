# Release v0.8.1

GitHub release: [Tarnished's Arsenal v0.8.1](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.8.1)

v0.8.1 contains the complete v0.8.0 feature and hardening release. The v0.8.0
tag was not published after its hosted packaged-app smoke could not observe the
WebView2 debugging endpoint, despite all compile, test, data, and bundle gates
passing.

- Reserve an available loopback port for packaged WebView2 smoke automation
  instead of guessing from a small fixed range.
- Give every launch a unique WebView2 data directory so an existing browser
  process cannot discard the requested debugging arguments.
- Add bounded startup retries, early process-exit detection, endpoint identity
  validation, GPU-independent runner arguments, temporary-profile cleanup, and
  per-attempt diagnostics.
- Preserve the full packaged workflow assertion: native search, selection below
  the podium, Compare, Paths, Affinity Watch, and saved-build reload.

The complete product changes are documented in the v0.8.0 release notes. The
patch changes only release-smoke reliability and version metadata; application
modeling and optimizer behavior are unchanged from the verified v0.8.0 commit.
