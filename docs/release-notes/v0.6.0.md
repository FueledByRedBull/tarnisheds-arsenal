# Release v0.6.0

GitHub release: [Tarnished's Arsenal v0.6.0](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.6.0)

- Rework optimizer preparation so estimate and execution share one immutable
  prepared search plan instead of rebuilding the same constraints and work units.
- Calculate base weapon attack rating and status once per stat/upgrade candidate,
  then apply Ash of War-specific deltas across compatible choices.
- Reduce open Katana `Max AR + Bleed` from roughly 270-281 ms to 4-5 ms in the
  representative release benchmark while preserving exact deterministic results.
- Harden async job identity, cancellation, polling, bounded analysis caches, and
  stale saved-build handling across Rankings, Paths, and Affinity Watch.
- Make every ranking-table row focus its result by click or keyboard without the
  horizontal drag-to-scroll handler swallowing ordinary clicks.
- Prevent a delayed dropdown blur from closing a selector that was immediately
  reopened during rapid interaction.
- Make release MSI and standalone EXE builds explicitly self-contained with one
  complete embedded runtime snapshot and no adjacent data directory.
- Make tag pushes the publishing path, require release validation, and publish
  the MSI, standalone EXE, versioned ZIP, immutable checksums, and machine-readable
  build provenance with every release.
- Pin release validation toolchains and require successful ordinary CI on the exact
  tag commit before release packaging can begin.
- Add Ruff, Pyright, Rust formatting, strict Clippy, and release metadata checks to
  CI and repair the existing Python tooling findings.
