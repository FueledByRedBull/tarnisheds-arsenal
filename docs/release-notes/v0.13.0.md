# Release v0.13.0

v0.13.0 improves the desktop workspaces, protects saved builds, and makes release
packaging and publication more reliable.

- Show combat stats and weapon scaling directly in compact ranking rows. Put the
  selected build and comparison differences first, improve contrast and selected
  states, and fix overlapping headers and controls at smaller window sizes.
- Compare path steps side by side by level, with pagination and clear starting
  stats and unavailable-gain labels. Show explicit analysis completion and stale
  states, and make Convergence's fixed stats and unsupported skill damage clear.
- Avoid unchanged ranking renders while scrolling, isolate progress updates from
  character controls, and reuse completed comparisons for identical requests.
- Serialize shared search jobs through cancellation completion. Cancel CSV exports
  when their inputs or workspace change and prevent late downloads.
- Preserve saved builds at the library limit, validate renamed and imported names,
  and keep readable presets accessible when storage writes fail. Prevent migration
  from restoring deleted builds, changing stat locks, or retaining stale results.
- Save Convergence's actual fixed stats and retain disabled result-lock settings.
  Invalidate pinned comparisons when the model or schema changes.
- Keep all weapon affinities in their proper families, report available upgrade
  levels accurately, and apply profile validation consistently to level searches.
- Bind extraction caches to their source regulation and support extraction paths
  containing spaces. Handle application, library, and MSI signing inputs correctly.
- Separate preview packaging from publication restrictions. Retry publication with
  the original build artifacts and verify remote asset hashes before completion.
- Update the locked PostCSS and nanoid development dependencies.

The optimizer's exactness argument remains conditional on exact arithmetic;
floating-point pruning has documented limits. Convergence mechanics remain
experimental. This release does not add enemy-defense or status-proc modeling.
