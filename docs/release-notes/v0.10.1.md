# Release v0.10.1

GitHub release: [Tarnished's Arsenal v0.10.1](https://github.com/FueledByRedBull/tarnisheds-arsenal/releases/tag/v0.10.1)

v0.10.1 is a focused installer and data-safety hardening patch for v0.10.0.

> **Convergence coverage remains beta; v0.10.1 is a stable application release.**
> Its verified model coverage is unchanged from v0.10.0.

- Pin the WiX UpgradeCode to the historical v0.9.x product family so future
  installers upgrade existing installations even when display typography changes.
- Align the title-bar and Windows product-name typography.
- Validate installer identity in source metadata and again against the built MSI.
- Directly test snapshot promotion: listed CSVs survive, stale CSVs are removed,
  unrelated files remain untouched, and unsafe manifest paths fail before writes.
- Compare bleed-only scoring with full status calculation under both Vanilla's
  scaling rules and Convergence's non-scaling rules.
- Normalize the documented `-99999` missing-status sentinel to zero and reject all
  other negative or non-finite status buildup while loading runtime data.
- Keep the existing objective wire ID while aligning its internal name with the
  visible `Bleed, then AR` behavior.
- Present a shorter user-first README with a current Rankings screenshot and record
  the final-AR recomputation invariant that protects displayed values from DP drift.

The v0.10.0 MSI used a different automatically generated UpgradeCode. GitHub showed
no direct MSI downloads before this correction; if that MSI was installed by another
route, uninstall it once before installing v0.10.1. Portable builds are unaffected.
