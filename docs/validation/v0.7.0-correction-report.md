# v0.7.0 correction and ranking-impact report

This report records the expected result changes from the v0.7.0 data/model
hardening. It distinguishes verified corrections from mechanics that remain out
of scope.

## Independent AR checks

`tools/phase4/validate_external_calculator.py` evaluates the public T. Clark App
1.14 static calculator data with that calculator's own curve and attack-rating
formula, then compares it with the current Rust optimizer. The selected base-game
cases avoid rows changed by later DLC patches.

All four raw values have 0.0000 observed drift. Tarnished.dev's current calculator
bundle independently reports the same Keen Uchigatana +25 inputs: 258.5 base
physical, 0.117 STR scaling, 1.428 DEX scaling, attack-element correction 10000,
and physical graph 2.

External sites are optional comparison inputs, not release dependencies. The T.
Clark snapshot identifies itself as App 1.14, and either site can change or become
unavailable.

## Extraction changes

- Rankable weapon configurations changed from 3,272 to 3,215.
- The 57 removals are exactly 42 `[NPC]` rows and 15 nonstandard rows whose own
  regulation configuration has `disableGemAttr=1`.
- The 15 unavailable configurations comprise Treespear Sacred; Great Club Heavy,
  Keen, Quality, Fire, Flame Art, Lightning, Sacred, Magic, Cold, Poison, Blood,
  and Occult; and Troll's Hammer Fire and Flame Art.
- Native-skill coverage is 1,116 matched rows with no unresolved or silently
  accepted rows.
- Passive-effect coverage is 120 resolved references plus three source-absent IDs
  recorded as explicit exclusions.

## AoW model changes

- All 317 `is_add_base_atk` rows use the reinforced weapon base component. The 151
  rows that the legacy motion/fixed-base-only formula would calculate as zero no
  longer silently collapse to zero.
- Legal route data contains 2,037 hit assignments across 220 skills and 273
  skill-route pairs. Another 676 lacking-FP variants are explicitly excluded.
- Effect data contains 3,021 numeric graph records. Coverage classifies 2,301 skill
  rows as resolved and 391 as having no gameplay effect.
- Fifteen conditional replacement/chained effect records remain intentionally
  unsupported and are individually documented instead of being treated as status
  buildup or persistent buffs.

`AoW First Hit` now compares the first damaging hit of legal routes. `AoW Full
Sequence` now compares complete legal routes and selects one deterministic best
route. Therefore AoWs such as Wild Strikes, Barbaric Roar, and Ghostflame Call can
move in rankings: mutually exclusive loop/finisher, handedness/charge, and R1/R2
branches are no longer added together. Status and stamina totals likewise include
only the selected route.

## Verification

- 75 Rust core tests.
- 13 Tauri tests, including real packaged-data Search, Paths, Affinity Watch, and
  cancellation command paths.
- 13 Vitest tests for generations, cache subscribers/rejections, adaptive polling,
  slow-poll non-overlap, and stop/unmount behavior.
- Rust formatting and strict Clippy, Ruff, Pyright, TypeScript production build,
  exact snapshot validation, and Phase 4 validation with zero warnings.

Release-mode v0.7.0 benchmark on a 16-logical-CPU Windows machine (one warmup and
five measured runs): Katana open Max AR was 3.9 ms median for 18,863 combinations;
Katana Max AR + Bleed was 4.1 ms; and all-weapons open Max AR was 256.7 ms plus
233.3 ms estimate preparation for 3,130,201 combinations. Exact and seven-choice
open-AoW cases remained at or below 0.1 ms. Compared with the final v0.6.0 binding,
the representative broad search improved from 283.1 ms to 256.7 ms while its
corrected player-only dataset reduced the search space from 3,149,097 to 3,130,201.

Enemy defense/negation, resistance growth, proc explosions, and universal
temporary-buff stacking remain outside the raw AR/AoW model. Poise/stance damage is
not part of this plan.
